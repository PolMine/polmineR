## Docker images with polmineR inside

Docker images with an installation of R and polmineR can be used for testing purposes. The Dockerfile in the folder 'polminer-opencpu' builds an image for hosting resources on an OpenCPU server (published as ghcr.io/polmine/polminer-opencpu and ghcr.io/polmine/polminer-opencpu-dev). The Dockerfile in the folder 'opencpu_restricted' adds access restrictions. 

See the 'OpenCPU'-vignette for further explanation.
